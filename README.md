# Deepoo AI

**Your Voice. Your Commands. Your AI.**

Deepoo AI is a personal AI assistant project built with Python. The goal is to develop an assistant that can understand natural-language instructions, answer questions, and perform useful tasks through controlled Python tools.

## Project Goals

* AI-powered conversations using the Gemini API
* Voice input and text-to-speech responses
* Application launching and permitted desktop tasks
* Web search and browser automation
* File and folder management
* Persistent memory for user preferences
* Safe execution of approved tasks

## Technology Stack

* Python
* Google Gemini API
* Git and GitHub
* VS Code

## Getting Started

Clone the repository:

```bash
git clone https://github.com/deepanshurajpoot777-cpu/deepoo-ai-assistant.git
```

Open the project directory:

```bash
cd deepoo-ai-assistant
```

Create a virtual environment:

```bash
python -m venv .venv
```

Activate it on Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

Run the application:

```bash
python main.py
```

## Security

API keys and other secrets must be stored in environment variables and must never be committed to GitHub.
